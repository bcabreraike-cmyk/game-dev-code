# Contribuyendo a Ludoforge

Gracias por tu interés en contribuir a Ludoforge. Por favor, lee nuestras guías de contribución antes de enviar un pull request.

## Cómo contribuir

1. Fork el repositorio
2. Crea una rama para tu feature o fix (`git checkout -b feature/amazing-feature`)
3. Realiza tus cambios
4. Asegúrate de que las pruebas pasen
5. Envía un pull request

## Reporte de bugs

Por favor, abre un issue describiendo el bug y los pasos para reproducirlo.

## Código de conducta

Por favor, respeta el [Código de Conducta](CODE_OF_CONDUCT.md).
